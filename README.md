# 秋招简历助手 · AutoFillCV

用于中国校园招聘网申的 Chrome 插件，当前版本 0.2.1。无需账号、后端服务或 API Key，可以直接加载 `extension` 文件夹。

## 安装和使用

1. 在 Chrome 地址栏打开 `chrome://extensions/`，打开右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 **`extension` 文件夹**（不是项目根目录）。
3. 将插件固定到工具栏，点击插件 →「导入 PDF / 编辑资料」。
4. 在「我的三份简历」选择模板并命名（如前端版、后端版、产品版），分别导入文字型 PDF，或展开「复制文字导入」粘贴简历文字。核对提取结果，补全教育、实习、项目等资料，点击「保存我的简历」。切换模板时自动保存当前修改；保存失败会停留在当前模板。
5. 打开招聘网站的申请表，在插件的「本次填写使用」选择需要的简历，再点击「扫描当前页面」。检查每一项的匹配关系，可在下拉框中手动改选资料来源。切换简历会清除旧的匹配预览，需要重新扫描。
6. 点击「填写已匹配字段」。默认跳过网页已有内容；需要覆盖时主动勾选覆盖选项。检查网页中的结果，再手动提交。
7. 「撤销上次填写」可恢复本页最近一次有效填写。你在填写后手动修改的字段会保留。刷新或关闭页面后撤销记录消失。

在 Windows 的 Chrome 使用 WSL 项目时，可以先把 `extension` 文件夹复制到 Windows 的目录再加载。每次修改代码后，在扩展管理页点击该插件的刷新按钮。

从 0.1.0 升级时，请更新原来加载的文件夹并刷新已有扩展，随后刷新编辑页面。保持相同的扩展身份才能读取原有本地数据。旧版单份简历自动迁移到「简历 1」，另外两份为空白；也可用旧版 JSON 备份恢复到当前模板。

## 三份简历与备份

- 固定三个独立模板，分别存储名称和完整资料，当前选择会在下次打开时保留。
- 编辑页和插件弹窗都可以切换；每份独立导入 PDF，切换时不会混入其他模板的提取原文。
- 网页扫描和填写使用当前模板；扫描后修改资料或在别处切换模板，会提示重新扫描。
- 「导出三份简历备份」包含全部三个模板、名称和当前选择，也包含当前编辑页未保存的表单内容。
- 新版备份恢复会替换并保存全部三份简历；旧版单份备份只替换当前编辑表单，核对后保存。
- 「清空全部三份简历」删除所有本地模板资料，保留三个空白模板入口。

## 资料字段

- 基本信息：姓名、英文名、性别、出生日期、民族、手机号、邮箱、微信号、籍贯、政治面貌、婚姻状况；保留现居城市及个人主页。
- 每条教育背景：学校名称、专业、学历、学位、开始时间、结束（毕业）时间、GPA、海外经历、学院、研究方向、学校城市、主修课程、学生干部经历。
- 实习经历和工作经历分别管理，每条包含：公司名称、职位、所在部门、工作类型、所属行业、工作地点、薪资、开始时间、结束时间、工作内容、工作成果。「工作内容」也可匹配网页的「工作描述」。
- 每条项目经历：项目名称、项目角色、开始时间、结束时间、项目描述、项目成果。
- 自我评价独立为一个板块；原有求职意向、技能、语言和奖项继续保留。

已有模板及旧备份仍可读取。旧版「实习 / 工作经历」统一保留到「工作经历」，请核对并将实习条目整理到「实习经历」；旧版「课程 / 荣誉」原文保留在「主修课程」。学历和学位独立保存；工作地点与意向城市分别匹配。薪资仅在明确的实习或工作经历分组内匹配，期望薪资不自动填写。网页只有「实习 / 工作经历」合并标题时，请在匹配预览中手动选择资料来源。

## 第一版能力与边界

- 中文界面；基本信息、求职意向、教育背景、实习经历、工作经历、项目经历、自我评价和补充信息。
- 教育、实习、工作和项目可分别新增多条，填写预览允许手动选择具体条目。
- 本地 PDF 文字提取：常见未加密 PDF 的文字流、Flate 压缩、对象流、中文 ToUnicode 字体映射。原始 PDF 不保存。
- 自动提取姓名、手机、邮箱、部分明确标注的资料、首条学校和学历，以及技能 / 荣誉 / 自评等明确标题下的文本。
- **PDF 是轻量解析器，并非完整 PDF 引擎；复杂多栏排版、自定义字体编码、特殊压缩等可能失败或顺序错乱。请核对原文与结果。实习、项目和完整教育经历需手动整理。**
- **图片或扫描型 PDF 暂未内置 OCR。** 无文字、乱码、加密文件会提示错误，可改用文字型 PDF 或复制文字导入。
- 页面匹配依据 label、ARIA、placeholder、字段名和分组标题，支持常规 input、textarea、原生 select 及可访问的开放式 Shadow DOM。
- 不自动操作自定义下拉框、联动省市、单选 / 多选、附件上传、日期弹层、跨域 iframe、封闭 Shadow DOM；不自动新增网页经历条目。页面每出现一组新字段，可重新扫描。
- 部分招聘系统只接受自身组件产生的交互，需要进一步做站点适配。**尚未在真实招聘网站完成兼容性验证，不承诺所有网申系统都能填写。**
- 不填写密码、验证码、证件号码和紧急联系人，不自动提交申请。

## 本地测试

项目不需要安装构建依赖。

```bash
# Node.js 22 或更新版本：解析、匹配、填写和撤销逻辑测试
node tests/core.test.js

# 在项目根目录启动本地测试页面
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://localhost:8765/tests/demo.html`，或启动服务后点击插件的「打开测试表单」。该表单不会发送任何资料。

建议在 Chrome 进行以下验收：

1. 导入一份文字型中文简历，核对姓名 / 电话 / 邮箱；导入扫描件时确认有明确提示。
2. 添加两条教育 / 实习经历，保存后重新打开编辑页，确认资料仍在。
3. 在测试表单检查匹配及预览，确认密码、验证码与只读字段被跳过。
4. 确认「意向岗位」的已有内容默认保留；主动允许覆盖后重新填写。
5. 手动修改一个已填字段，再撤销，确认手动修改保留，其余恢复。
6. 导出备份并恢复；刷新编辑页面确认已保存的资料正确。
7. 为三个模板分别设置不同岗位和名称；来回切换并重开插件，确认独立保存、选择持久化。
8. 扫描后切换模板，确认匹配预览清空；重新扫描后填写的内容来自新模板。
9. 用旧版资料升级，确认资料迁移到第一份；备份与恢复后确认三份资料及当前选择均保留。

本次修改在可用的 JavaScript 运行环境中通过了 17 项逻辑检查，覆盖新字段匹配、实习 / 工作分组、旧资料迁移、三份模板保存 / 备份恢复及填写撤销，并检查了界面脚本语法。当前环境没有 Node.js，未运行完整的 `npm test`（含 PDF 解析测试）；也没有可用的 Chrome 运行时，尚未执行浏览器端的安装、布局和完整交互验收。

## 隐私与权限

PDF、复制的文字和资料均在本地处理。仅三个模板的名称、规范化后的简历资料、保存时间和当前模板选择存入 `chrome.storage.local`，不使用云同步，无统计代码，无远端请求。JSON 备份含个人信息，请妥善保存。卸载插件或点击「清空全部三份简历」可删除保存的资料；已导出的文件需自行删除。

权限仅包含 `storage`、`activeTab` 和 `scripting`。页面访问在主动点击插件时临时授予，不申请所有网站的永久访问权限，参见 [Chrome activeTab 官方文档](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)。填写到招聘页面的资料将交由相应招聘网站处理。

## 文件结构

```text
extension/
  manifest.json       Chrome Manifest V3 配置
  popup.*             扫描、匹配预览、填写入口
  options.*           PDF 导入、资料编辑与备份管理
  content.js          识别网页字段、填写、撤销
  lib/pdf.js          离线轻量 PDF 文字提取
  lib/profile.js      资料结构与简历文本提取
  lib/templates.js    三份简历存储、旧数据迁移与备份验证
  lib/matcher.js      中文 / 英文字段匹配
  styles.css          共享界面样式
  icons/              原创 SVG Logo 与多尺寸 PNG 图标
tests/                核心逻辑测试与本地网申测试页
tools/package.py      生成可供解压加载的发布包
tools/build_icons.py  无依赖生成矢量 Logo 和 PNG 图标
```

后续可按实际使用的招聘网站补充自定义组件适配、完整经历解析，以及可选的本地 OCR。

## Logo

深绿色底上的简历纸张与浅绿色向上箭头，表示简历填写及求职进展。矢量原稿为 `extension/icons/logo.svg`；工具栏、扩展管理页及页面图标使用 16 / 32 / 48 / 128 像素 PNG，另有 512 像素原图。运行 `python3 tools/build_icons.py` 可从统一图形定义重新生成所有图标。
